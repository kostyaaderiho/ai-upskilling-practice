# Research: Экспорт библиотеки

Нерешённых `NEEDS CLARIFICATION` нет: оба вопроса закрыты в сессии clarify (все книги; 400).

## 1. Формирование CSV без зависимостей

- **Decision**: собственная функция экранирования по RFC 4180. Столбцы: `id,title,author,read`.
  Поле берётся в двойные кавычки, если содержит `,`, `"`, `\r` или `\n`; внутренние кавычки
  удваиваются. Разделитель записей — `\r\n`; завершающий перевод строки после последней записи
  ставится. `read` пишется как `true`/`false`.
- **Rationale**: правило короткое, покрывается тестами; конституция (III) запрещает новую
  зависимость ради нескольких строк кода.
- **Alternatives considered**: пакет `csv-stringify` (отклонён: зависимость без обоснования);
  экранирование всех полей подряд (отклонено: лишний шум в простых данных).

## 2. Формат JSON

- **Decision**: тело ответа — JSON-массив книг (`id`, `title`, `author`, `read`), тот же порядок,
  что у `listBooks()`. Пустая библиотека даёт `[]`.
- **Rationale**: совпадает с составом данных CSV (FR-002); массив проще потребителю, чем объект
  с обёрткой.
- **Alternatives considered**: объект `{ books, exportedAt }` (отклонён: расширяет контракт без
  требования).

## 3. Валидация формата и ошибка

- **Decision**: `parseExportFormat(value: unknown): ExportFormat` в `storage.ts` принимает только
  точные строки `json` и `csv`; иное (отсутствует, пусто, другой регистр, массив при повторном
  параметре) бросает `UnsupportedFormatError`. Ручка отвечает `400 { detail }`.
- **Rationale**: доменные ошибки — классы в `storage.ts`, роут переводит в статус (конвенция
  проекта); регистр зафиксирован в Assumptions спецификации.
- **Alternatives considered**: 422 из `docs/B-4.md` (отклонён решением из clarify).

## 4. Заголовки ответа

- **Decision**: `application/json` для JSON и `text/csv; charset=utf-8` для CSV.
  `Content-Disposition` не добавляется.
- **Rationale**: достаточно для таблиц и клиентов; вложение — расширение контракта, которого
  спецификация не требует.

## 5. Порядок маршрутов

- **Decision**: `GET /books/export` регистрируется рядом с `GET /books/recent`, до любых
  будущих ручек `/books/:id`.
- **Rationale**: иначе `export` будет воспринят как `:id` при добавлении B-8. Сейчас конфликта
  нет, но порядок фиксируем заранее.

## 6. Риск CSV-инъекции формул

- **Decision**: значения не модифицируются; риск зафиксирован как известный.
- **Rationale**: названия с `=`, `+`, `-`, `@` в начале табличные редакторы могут трактовать как
  формулу. Нейтрализация изменила бы экспортируемые данные и не входит в спецификацию;
  при необходимости — отдельная задача.
