# Data Model: Экспорт библиотеки

Новых сущностей в хранилище нет; экспорт читает существующие.

## Book (существует, `src/storage.ts`)

| Поле | Тип | Правило экспорта |
|------|-----|------------------|
| `id` | number | как есть |
| `title` | string | CSV: экранируется по правилам RFC 4180 |
| `author` | string | CSV: экранируется по правилам RFC 4180 |
| `read` | boolean | `true` / `false` |

## Новые типы (`src/storage.ts`)

- `ExportFormat` = `"json" | "csv"`.
- `UnsupportedFormatError` — доменная ошибка неизвестного или отсутствующего формата.

## Export (производная, не хранится)

Снимок всех книг на момент запроса в выбранном формате. Состояния и переходы отсутствуют;
экспорт не изменяет `books`.
