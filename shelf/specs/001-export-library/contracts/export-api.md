# Contract: GET /books/export

## Запрос

`GET /books/export?format=<json|csv>`

| Параметр | Обязателен | Допустимые значения |
|----------|------------|---------------------|
| `format` | да | `json`, `csv` (строго в нижнем регистре) |

## Ответы

### 200, `format=json`

`Content-Type: application/json`. Тело — массив всех книг:

```json
[{ "id": 1, "title": "Дюна", "author": "Фрэнк Герберт", "read": false }]
```

Пустая библиотека: `[]`.

### 200, `format=csv`

`Content-Type: text/csv; charset=utf-8`. Первая строка — заголовки, далее по строке на книгу,
разделитель записей `\r\n`:

```text
id,title,author,read
1,Дюна,Фрэнк Герберт,false
2,"Война, и мир",Лев Толстой,true
```

Пустая библиотека: только строка заголовков.

### 400, формат не указан или не поддерживается

```json
{ "detail": "Unsupported export format" }
```

Данные в таком ответе не возвращаются.

## Гарантии

- Экспорт только читает данные и не меняет хранилище.
- JSON и CSV содержат один и тот же набор книг и полей.
