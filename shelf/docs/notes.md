## 3.2 Отладка и тесты

- B-1: что проверяли тесты по одному коду: ничего — агент сам увидел, что
  `(read * total) / 100` не проценты, и написал тесты по смыслу (5 из 10 → 50),
  они упали. Догадался по имени функции, комментарию «в процентах» и умножению
  вместо деления. Если бы вывел ожидания из формулы — были бы зелёные, то есть
  код сверялся бы сам с собой. На функции без говорящего имени так не повезёт,
  ожидаемое поведение надо давать самому. Починка: `(read / total) * 100`,
  тесты не менял, `npm run check` зелёный.
- B-2: промпт из трёх частей (`/books/recent` отвечал 500):

  ```
  1. TypeError: Cannot read properties of undefined (reading 'id')
     at src/storage.ts:36:23, at Array.from, at Module.recent (storage.ts:34:16)
  2. Функция recent(n = 3) из src/storage.ts
  3. Ожидаю: до трёх последних книг, новые первыми; пустой список — [].
     Исправь и добавь тесты на 0, 1 и 5 книг.
  ```

  Третья часть нашла второй баг: кроме `all[all.length - i]` (индекс за концом
  массива) мешал `Array.from({ length: n })` — всегда ровно `n` элементов, то
  есть на 1–2 книгах падало бы и после правки индекса. По стеку его не видно.
  Стало `listBooks().slice(-n).reverse()` плюс `tests/storage.test.ts`.
- Галлюцинация: ошибка tsc, ссылка на документацию, промпт с обратной связью:

  ```
  src/validation-draft.ts(1,10): error TS2305:
  Module '"express"' has no exported member 'validateBody'.
  ```

  https://expressjs.com/en/5x/api.html — у Express 5 есть `json`, `urlencoded`,
  `static`, `raw`, `text`, `Router`, валидации тела нет вообще. `validateBody` со
  схемой — это `express-validator`/zod, выданные за Express. Промпт:

  ```
  npm run check: error TS2305: Module '"express"' has no exported member
  'validateBody'. В документации Express 5 такого экспорта нет — только json,
  urlencoded, static, raw, text, Router. Предложи, как проверить, что title —
  строка, без новых зависимостей. Код пока не меняй.
  ```

  Правдоподобное имя — не доказательство. Выдуманный экспорт `tsc` поймал
  сразу, потому что у Express есть типы; выдуманный аргумент или «этот флаг
  делает X» не поймал бы. `@ts-ignore` тут был бы не починкой, а сокрытием.
  Хвост: `validation-draft.ts` зря попал в коммит «Task 1-2», лежит в `src/` и
  роняет `npm run check`. Удалить.
